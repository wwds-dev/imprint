# Support

Imprint is a macOS desktop studio of AI agents for writing, audiobooks, music, video and social posts, maintained by one person in their own time. There is no paid
support and no guaranteed response time.

## Where to ask

| You want | Go to |
|---|---|
| Help running it, or a question about how it works | the README (it is the full manual) and the in-app Learning Centre first, then a [GitHub issue](https://github.com/wwds-dev/imprint/issues) |
| To report a bug | a GitHub issue with the version in the header bar, your macOS version, what you did, what you expected and what happened. Do not paste API keys or the contents of `.env`, manuscripts, voice samples, or anything else you would not publish |
| To report a security problem | [SECURITY.md](SECURITY.md), privately, never in a public issue |
| To suggest a feature | a GitHub issue; `SUGGESTIONS.md` lists what is already considered |

## What to expect

Issues are read **about once a week**; a reply within 7 days is the target, not a promise.
Fixes land when the maintainer has time.

## What Imprint is not

- It does not promise sales, income, listings or audience results, and nobody here can.
- What the agents write, narrate or generate is model output: you review it and you are responsible for what you publish with it.
- It uses your own API keys with the providers you enable, and those calls cost money at the provider's prices. Imprint shows its estimate; the provider's bill is what counts.

## Known limits

- macOS only (developed on Apple Silicon); published as source, with no binary release.
- Model providers change models, prices and limits without notice; a provider error is the most common fault, and the message names the provider.
- Posting and store connectors (YouTube, Reddit, Pinterest, PublishDrive) depend on the provider's API and your account; the PublishDrive connector has not been tested against a live account.
