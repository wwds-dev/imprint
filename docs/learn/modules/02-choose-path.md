# Choose an income path

> **Outcome:** choose one buyer, bounded offer, acquisition channel, and next
> evidence step. This lesson does not estimate what you will earn.

## Prerequisites

- You can name a reachable group rather than “everyone.”
- You are willing to run a small test before automating a catalogue or campaign.
- You can record cost and human time, including failed output and revisions.

## Four useful operating loops

| Path | Good first use | Primary observed decision metric | Start with |
|---|---|---|---|
| Productised client service | Fast buyer feedback and a tightly scoped deliverable | Economic contribution per accepted order and human hour | Client Gigs or Site Builder |
| Owned catalogue | A demonstrated reader/listener need and reusable IP | Contribution by release cohort and attributed source | Draft → Publish |
| Content-to-offer funnel | One existing offer with a trackable next action | Paid/intended actions per qualified visit | Social Media Campaign Manager → Video & Ad Generator → Web Developer |
| Authorised creator venture | An owned, managed, or accurately disclosed profile | Contribution and retention by buyer/subscriber cohort | Venture signals → Creator |

## Choose with evidence, not excitement

1. Write one reachable buyer group.
2. Write the observed problem and its source/date. If it came from a model,
   trend score, competitor, or demo dataset, label it a hypothesis or proxy.
3. Bound the deliverable: quantity, format, exclusions, review, and revision.
4. Choose one channel where a denominator can be recorded.
5. Choose the smallest paid or high-intent test that avoids speculative bulk
   production.
6. Name the human approval gates: rights, claims, identity/consent, public
   posting, client acceptance, or money movement.

## Path decision card

```text
Buyer:
Observed problem and evidence label:
Offer and exclusions:
Price or price test:
One acquisition channel:
Qualified opportunity definition:
Primary measured outcome:
Budget/time/quality guardrails:
Next smallest evidence step:
```

## How to read the result

Choosing a path is a **HYPOTHESIS**, not a business result. External trend data
can prioritise tests; generated strategy can structure them. Only owned
behaviour with a denominator and observed transactions can evaluate them.

## Verification

- [ ] One buyer, one offer, one channel, and one primary outcome are named.
- [ ] The evidence source and label are explicit.
- [ ] The next step can be stopped without leaving a large sunk catalogue.
- [ ] Human approval remains at irreversible actions.

## Common failures

**The offer is “content” or “AI services”:** state the buyer-visible outcome and
boundary.  
**The metric is likes or generated assets:** connect it to an intended or paid
action.  
**Everything is being tested at once:** hold audience, offer, channel, and price
stable enough to learn which stage failed.
