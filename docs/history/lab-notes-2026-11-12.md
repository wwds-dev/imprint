# Imprint and vidforge: lab notes

Moved verbatim from the lab-root `AGENTS.md` on 2026-11-12 (consolidation; original kept in
`backups/agents_md_pre_consolidation_20261112/`). This file is **not auto-loaded**: read it when
working on this area. Statements carry their own dates and may be stale, so check the code before
relying on one. Rules that must always hold were lifted into the root `AGENTS.md` (Hard rules).

---

  - `imprint/` — "Imprint.app", the create-and-publish studio forked from `sentinel_ai`
    (was `atelier/`, then `create_and_publish/`; the only remaining uses of that old name
    are the deliberate migration constants `PREVIOUS_APP_NAMES` in
    `services/runtime_paths.py` and `PREVIOUS_DB_NAMES` in `services/database.py`, which
    carry the user's keys and database across the rename — renaming it again means moving
    `~/Library/Application Support/Imprint/` too). **Eight agents** behind mode tabs:
    Write (author · manuscript) · Audio (audiobook · music) · Video · Social · Web · Gigs ·
    Creator. `chat` is the Studio Assistant behind the **Assistant** workspace tab (wired 2026-09; a test pins it).
    **Imprint must never reference the venture dashboard that moved out to `backstage/` on
    2026-09-27** — not its name, not its old workspace label, in code, docs, tests or file
    names; `tests/test_retired_names.py` fails the build if either reappears (it builds
    the words at runtime so it does not trip itself). The same day Imprint's history was
    rewritten with `git filter-repo` to match and force-pushed; Creator's adult-platform
    drafting rule and performer records were removed at the same time. Pre-rewrite
    snapshot: `backups/pre_backstage_split_20260927-232944/`. The rewrite changed commit
    SHAs, so `.gitleaksignore` was re-pinned — any future rewrite needs the same.
    The shell is a header bar over two fixed rails; the QSplitter was removed because it
    let panes compress past their children's minimums, which Qt resolves by overlapping.
    The window opens **fullscreen**, which covers the macOS menu bar — so Imprint's own
    **menu bar item** (`ui/tray.py`, added 2026-10-06) is only ever visible while another
    app is in front, which is exactly when it is wanted. Two entries, Open and Quit.
    **It does not hide to the menu bar**: closing the window still quits the app, unlike
    SONAR and Lab Hub, so a *Running* tile with no window means something else. Quit is
    wired to `window.close()`, never `QApplication.quit()` — `closeEvent` is where the
    manuscript is saved and the worker `QThread`s are cancelled, and Qt aborts on a
    thread destroyed while running. The glyph is a template image drawn by
    `scripts/make_tray_icon.py` (`assets/tray.png` + `@2x`, both in `Imprint.spec`), not
    derived from `icon_source.png` — flattening that artwork gives the silhouette of its
    tile, not the book.
    Paid work billed per unit rather than per token (images, video renders, TTS) is priced
    from `config/pricing.json` -> `per_unit_usd` via `services/per_unit_pricing.py`, where
    **a rate of 0 means unknown, not free**. `main.py --selftest` covers the packaging
    traps below plus proof that vidforge shipped in the bundle.
    **In `autosync_repos.txt` with the `push-only` flag** — autosync pushes commits that
    already exist here and never stages, commits or publishes an untracked branch. Plain
    sweep mode was tried from 2026-09-12 and produced three `autosync: <timestamp>` commits
    in as many nights, one burying most of a Learning Centre rewrite; `push-only` exists
    because of it. Use the same flag for any repo a person or an agent works in.
    There is no `core.hooksPath`, `.git/hooks/` is empty, and the LaunchAgent fires at 03:30
    — so a push landing seconds after a commit is a person or an agent session, never a hook.
    - `vidforge/` — topic → narrated/illustrated video pipeline (script → TTS →
      imagery → Ken Burns → captions → music → thumbnail), reached through Imprint's
      **Reel** agent. Upload is manual and gated behind two separate opt-ins.
      **Absorbed into Imprint on 2026-09-30**: it is ordinary Imprint source now, not
      its own repo and not a standalone app. The `vidforge.app` bundle, its build script
      and its `launchctl` nightly job are gone — an unattended render is a paid path
      outside Imprint's request guard — and the old repo's history is archived as a git
      bundle in `archive/vidforge_standalone_2026-09-30/`. It keeps its own directory
      because that directory is also the pipeline's data directory in a checkout:
      `config.yaml`, `topics.txt`, `assets/` and the render library live there, and
      moving the package would have moved the library with it. Frozen, `PROJECT_ROOT` is
      still `~/Library/Application Support/vidforge/`. Long-form and vertical social
      clips are the same `produce()` call with config overrides, which is how Imprint's
      Social mode asks for clips without owning a video pipeline.
