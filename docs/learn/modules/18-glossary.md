# Glossary

> **Outcome:** know what a term in the lessons means, in one line, and which
> lesson explains it in full.

## Prerequisites

None. Search for the term, or scroll: entries are in alphabetical order, and
each heading is a link target the other lessons point to.

## Terms

### Approved version

A frozen copy of a Quill draft, made with **Approve Write Draft…** in Press.
Later edits do not change it. Exports and release kits are made from it.
[Press](21-publish.md).

### BEST FIT

The badge on the recommended provider (in the Provider menu) and on the
recommended model inside the selected provider (in the Model menu), ranked on
quality, fit and known price. It only marks; it never switches your selection.
[Providers, models, and Best Fit](12-best-fit.md).

### Contribution

What one sale leaves after its variable costs. *Cash contribution* is revenue
minus refunds, fees, AI and media cost, fulfilment, paid acquisition and
contractors; *economic contribution* also subtracts the owner's hours at a
chosen hourly value. Neither is profit. [Unit economics](33-unit-economics.md).

### Denominator

The number a rate is divided by: the visitors, listeners or offers a count of
sales or clicks came from. Without it, "40 sales" says nothing about
conversion. [Evidence before production](30-evidence.md).

### Eligible route

A provider and model that pass every check for this request: a key where one
is needed, the permission box, the agent's allowed providers, availability
and budget. Only an eligible route can be sent.
[Access, permissions, and privacy](13-access-privacy.md).

### Evidence passport

A short form that records where a number came from: source file, window,
population, numerator, denominator, currency, and what it does and does not
let you conclude. [Evidence before production](30-evidence.md#evidence-passport).

### Frozen app

`Imprint Studio.app` built with `scripts/build_app.sh`: a snapshot of the code with
its own Python, keeping keys and data in
`~/Library/Application Support/Imprint/`. Code edits need a rebuild.
[Files, launcher, and recovery](15-files-recovery.md).

### Live launcher

`Imprint Studio.app` installed with `scripts/install_app.sh`: a small launcher that
runs the project folder's current code and reads its `.env` and `data/`.
[Files, launcher, and recovery](15-files-recovery.md).

### Local model

A model that runs on this Mac through Ollama or LM Studio. It costs nothing,
needs no key or permission box, and sends nothing to a provider.
[Add a key](13-access-privacy.md#add-a-key).

### Permission box

One toggle per paid provider, in the Assistant workspace (**Cloud text
models**, **Paid media**). A cloud request is sent only when its provider's
box is ticked. The boxes start unticked at every launch.
[Access, permissions, and privacy](13-access-privacy.md).

### Preflight

The checks and estimate Imprint makes before a request is sent: route,
permission, budget caps and the most the request can cost. Nothing is spent
during preflight. [Costs, estimates, and limits](14-costs-limits.md).

### Project

A named container in the left rail that groups chats, drafts, outputs and an
optional daily spend cap for one piece of work.
[Projects, saving, and exports](11-projects.md).

### Reserve

The amount the budget caps hold back for a request while it runs: the most it
can cost (for text, a full-length reply). What is actually billed replaces it
when the request finishes. [Costs, estimates, and limits](14-costs-limits.md).

### Setup target

A recommended route that is not ready yet (a missing key, an unticked box, a
capability or budget gap), shown as **BEST AVAILABLE** or setup wording. It
tells you what to set up, not that the action will work now.
[Providers, models, and Best Fit](12-best-fit.md).
