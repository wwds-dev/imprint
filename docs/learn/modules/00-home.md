# Learning Centre

> **Outcome:** choose the shortest lesson or guided path that leads to a
> verified result. Imprint will help you produce and measure work; it will not
> turn generated output into evidence of demand.

## Start from your goal

| Goal | Begin here | The result you should leave with |
|---|---|---|
| Learn the interface | [Navigate Imprint](10-navigate.md) | You can find the correct agent and read its status. |
| Make a first asset | [First verified result](01-first-result.md) | One edited, saved output with a known route and cost state. |
| Decide what to sell | [Choose an income path](02-choose-path.md) | One buyer, bounded offer, channel, and next evidence step. |
| Learn one tool | Open **Agent Academy** in the contents | A control-by-control run and acceptance checklist. |
| Measure a venture | [Evidence before production](30-evidence.md) | A labelled observation that permits a specific next test. |
| Fix a failure | Search the exact button label or error text | An anchored recovery procedure, not another blind retry. |

## Prerequisites

None. If Imprint opens, the Learning Centre remains local and usable even when
no paid provider is configured.

## Readiness check

- [ ] I know which project owns this work.
- [ ] I know whether the selected route is local or cloud.
- [ ] I can explain the **BEST FIT** recommendation or why I overrode it.
- [ ] I have a comfortable spend limit for paid work.
- [ ] I know where the output and partial output will be saved.
- [ ] I have an acceptance checklist before generating at scale.
- [ ] A human still approves public, paid, identity, rights, and consent actions.

## The operating loop

```text
Observe → choose one offer → produce → review → distribute → measure → decide
```

Automation belongs after the loop produces trustworthy evidence. Faster output
does not repair an unclear offer, missing denominator, negative contribution,
rights problem, or unreviewed public claim.

## How this centre is organised

**Foundations** explains shared controls. **Agent Academy** teaches the exact
tool you are operating. **Income Lab** turns outputs into bounded experiments
and honest decisions. Search looks inside headings and paragraphs and opens the
matching section directly.

### Verification

You are ready to continue when you can state: the goal, the project, the next
small action, what will count as success, and which lesson covers it.

## Common failures

**You are reading everything in order:** start from the goal or search the exact
control in front of you.  
**The goal is “make money with AI”:** choose one buyer, offer, channel, and next
evidence step before generating assets.
